User Management

•server
Summary

The User Management module covers the complete process of managing users on a Linux server, starting with understanding different user types and creating or modifying accounts using tools like useradd, usermod, and userdel. It also explains group management and how to implement least-privilege access using groups and sudo roles. The module focuses on security practices such as password policies, SSH key authentication, and protecting home directory permissions. Additionally, it includes monitoring login activity, auditing user accounts, and managing resource limits. Finally, it teaches how to lock, disable, or expire accounts to maintain a secure and production-ready server environment.
