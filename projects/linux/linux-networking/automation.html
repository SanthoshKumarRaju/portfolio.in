  echo "True"

  echo $i

  echo "Running check"

fi

Goal: Understand how Ansible automates infrastructure provisioning, configuration, and deployment using agentless architecture.

  1. What is Ansible
    Ansible is an open-source automation tool used for configuration management, application deployment, and infrastructure provisioning.
  2. Why Ansible
    • Agentless (uses SSH)
    • Simple YAML syntax
    • Easy to learn
  3. Basic Architecture
    Control Node → SSH → Managed Nodes
  4. Agentless Model
    No agents required on target machines.
  5. Installation
    apt install ansible
  6. Inventory File
    [web]
192.168.1.10
192.168.1.11
  7. Ad-hoc Commands
    ansible all -m ping
  8. Modules
    • ping
    • copy
    • yum/apt
  9. Playbooks
    YAML files defining automation tasks.
  10. Basic Playbook
    - hosts: web
  tasks:
    - name: Install nginx
      apt:
        name: nginx
        state: present
  11. Run Playbook
    ansible-playbook playbook.yml
  12. Idempotency
    Running playbook multiple times gives same result.
  13. Variables
    vars:
  app_port: 8080
  14. Handlers
    Triggered when changes occur. 
    notify: restart nginx
  15. Roles
    Organized structure for reusable code.
  16. Role Structure
    roles/
  web/
    tasks/
    handlers/
    templates/
  17. Templates
    Jinja2 templates (.j2)
  18. Conditionals
    when: ansible_os_family == "Debian"
  19. Loops
    with_items:
  - nginx
  - curl
  20. Tags
    --tags "install"
  21. Vault (Secrets Management)
    ansible-vault encrypt file.yml
  22. SSH Key Setup
    ssh-copy-id user@server
  23. Parallel Execution
    Runs tasks across multiple nodes simultaneously.
  24. Dynamic Inventory
    Used for cloud environments.
  25. Ansible with Docker
    Manage containers
  26. Ansible with Kubernetes
    Deploy pods/services
  27. CI/CD Integration
    • Jenkins
    • GitHub Actions
  28. Performance Consideration
    • Use forks for parallelism
  29. Common Issues
    • SSH connection failure
    • Permission issues
    • YAML syntax errors
  30. Troubleshooting Flow
    Check inventory
Check SSH
Validate YAML
Run with -vvv
  31. Best Practices
    • Use roles
    • Keep playbooks modular
    • Use version control
  32. Real-World Use Cases
    • Server provisioning
    • Application deployment
    • Network automation
  33. Summary
    Ansible simplifies infrastructure automation using agentless architecture, making it powerful for configuration management and deployment.
Completion check: You should now understand how Ansible automates infrastructure and configuration management.
